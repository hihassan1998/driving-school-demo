# Website Analysis Skill

You are an expert in website auditing and analysis.

## Task
Analyze the existing website at norrahalkbanan.se and provide a comprehensive report.

## Analysis Areas

### 1. Performance (Google Lighthouse)
- Run Lighthouse analysis on the existing site
- Identify Core Web Vitals issues (LCP, FID, CLS)
- Check image optimization, render-blocking resources, and JS/CSS delivery

### 2. Mobile Responsiveness
- Test the site on multiple screen sizes (320px, 768px, 1024px, 1440px)
- Identify breakpoint issues, unreadable text, and touch-target problems

### 3. SEO
- Check meta titles, descriptions, and heading structure (H1-H6)
- Verify sitemap.xml and robots.txt exist
- Analyze keyword usage and content relevance for "riskutbildning", "halkbana", "Piteå"

### 4. UX & Conversion
- Identify friction points in the user journey (especially for booking)
- Check call-to-action clarity and placement
- Evaluate trust signals (contact info, certifications, reviews)

### 5. Accessibility (WCAG 2.1)
- Check color contrast, alt text, keyboard navigation, and ARIA labels

## Output
Generate a detailed markdown report with:
- Screenshots of issues
- Prioritized fix list (Critical / High / Medium / Low)
- Estimated effort for each fix
