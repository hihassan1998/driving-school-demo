# Design System Skill

You are a senior UI/UX designer creating a design system for Norra Halkbanan.

## Brand Context
- **Industry:** Traffic safety / driving school (Riskutbildning 2)
- **Location:** Piteå, Sweden
- **Existing brand elements:** Blue color scheme, practical/training-focused
- **Tone:** Professional, trustworthy, approachable, safety-focused

## Design Principles
1. **Trustworthy** — Use clean, professional layouts with clear safety messaging
2. **Accessible** — WCAG 2.1 AA compliant with good contrast
3. **Mobile-first** — All designs work beautifully on phones (where most users will book)
4. **Conversion-focused** — Clear paths to booking

## Color Palette
- Primary: #1a5276 (deep blue — trust, safety)
- Secondary: #2e86c1 (medium blue — action/CTA)
- Accent: #f39c12 (warm gold — highlights, warnings)
- Neutral: #f8f9fa (light bg), #343a40 (dark text)
- Success: #27ae60 (green for confirmations)

## Typography
- Headings: Inter (sans-serif, modern, readable)
- Body: Inter or system fonts
- Hierarchy: H1 (2.5rem), H2 (2rem), H3 (1.5rem), Body (1rem)

## UI Components (based on shadcn/ui)
Use shadcn/ui component library as the foundation[reference:5][reference:6]:
- Button: Primary (blue), Secondary (outline), Destructive (red)
- Card: For service listings, team members
- Form: For booking, contact
- Navigation: Simple header with clear CTAs
- Footer: Contact info, opening hours, social links

## Layout Structure
1. **Header**: Logo + Navigation (Om oss, Tjänster, Boka, Kontakt)
2. **Hero**: Strong visual (training track image) + headline + CTA button
3. **Services**: 3-4 cards explaining what they offer
4. **Why Us**: Trust-building section (experience, equipment, location)
5. **Booking CTA**: Direct link to bokningskoll.se
6. **Footer**: Contact, address, phone, email, social

Provide Antigravity with reference images or screenshots of similar professional sites (e.g., other driving schools, safety training companies) to guide the visual style[reference:7].
